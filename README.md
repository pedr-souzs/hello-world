# Hello World

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)

Projeto introdutório de **HTML**, com uma página simples exibindo a mensagem “Hello World”.

## Sobre o projeto

O arquivo `index.html` apresenta uma estrutura HTML básica e um título de nível 1. O repositório também contém os arquivos `style.css` e `script.js`, que **estão vazios no estado atual** e podem ser usados em exercícios futuros.

## Estrutura

```text
hello-world/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Tecnologias

- **HTML5:** utilizado na página.
- **CSS3 e JavaScript:** arquivos preparados, sem estilos ou scripts implementados até o momento.

## Conceitos praticados

- Estrutura inicial de documentos HTML.
- Metadados no `<head>`.
- Título visível com `<h1>`.
- Organização inicial de arquivos de um projeto web.

## Como executar

1. Clone ou baixe o repositório.
2. Abra `index.html` em um navegador.

Nenhuma instalação adicional é necessária.
